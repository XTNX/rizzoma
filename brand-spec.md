# RIZZOMA — brand spec / дизайн-система лендинга

Файл фиксирует систему, по которой собран [`index.html`](index.html). Любая правка страницы должна
опираться на эти токены, а не вводить новые цвета/шрифты «на глаз».

> **Что здесь настоящее, а что нет.** Событие, площадка, дата и составы — реальные, по анонсу
> организаторов. **Цены билетов не объявлены** (в карточках стоит «уточняется»), а оплата на сайте —
> клиентская имитация: карты не обрабатываются, деньги не списываются, билет не выдаётся.
> «БД» рефералов живёт в `localStorage`.

---

## 1. Design read

| Параметр | Значение |
|---|---|
| Артефакт | Лендинг организации: манифест + афиша + карточка события + мок-чекаут + реферальная механика |
| Аудитория | Рейв-аудитория Санкт-Петербурга, «закрытый клуб» |
| Визуальный язык | Motion / Experimental: `field-io` × `active-theory` + авторский слой «нео-трайбл + фракталы» |
| Режим | Greenfield |
| visual-variance | 8 · motion-intensity 8 · information-density 5 · asset-dependence 3 · brand-fidelity 9 |

Насмотренность: Boiler Room / Draaimolen / Dekmantel / ADE; тёмная мода — Rick Owens, Balenciaga,
A-COLD-WALL*. Точечный приём Balenciaga post-2017: оверсайз-заголовки всё-caps на разделителях
секций и плоские текстовые CTA (`.btn--flat`) там, где нужна контрастная тишина.

## 2. Токены

```css
--bg:#08080A          /* базовый фон            */
--bg-raised:#111114   /* карточки, панели       */
--bg-sunken:#050506   /* «утопленные» секции    */
--ink:#F2F1EC         /* основной текст         */
--ink-muted:#8B8B93   /* вторичный текст        */
--accent-primary:#7B2FF7   /* логотип, узлы сети, primary CTA */
--accent-secondary:#FF2E4D /* ошибки, decline, дисклеймеры    */
--accent-toxic:#B6FF3C     /* success, разлочка тира, фокус   */
--line:rgba(242,241,236,0.08)
```

Промежуточные оттенки сети генерируются в `oklch`: фиолетовый слой `oklch(0.52 0.22 300)`,
поверх — «прожиг» `oklch(0.86 0.21 128)` с альфой = степень разлочки. **Интерполяция оттенка
между 300 и 128 запрещена** — она проходит через cyan и даёт generic cyber-неон.

- **Шрифты**: Space Grotesk (display) · JetBrains Mono (лейблы `REF_CODE:`, цифры, таймер) · Sora (текст).
- **Сетка**: 8pt (`--s1…--s8`), боковые поля `clamp(20px,5vw,72px)`, макс. ширина 1440.
- **Радиус**: 0 везде. **Тени**: только свечение узлов сети, CSS-теней у карточек нет.
- **Motion**: `cubic-bezier(0.83,0,0.17,1)`, 200 / 520 / 900 ms; стаггер-появление по `--d`.

## 3. Логотип

Источник — [`../TD visuals/references/13.svg`](../TD%20visuals/references/13.svg). Контур вынесен
в **один источник правды**: инлайн-`<symbol id="rz-logo">` в начале `<body>`.

| Где используется | Как |
|---|---|
| Навигация, футер, карточка «одна ночь» | `<svg class="mark"><use href="#rz-logo"/></svg>`, цвет через `currentColor` |
| Ядро генеративной сцены | `new Path2D(#logoPath.d)` → `cfg.logo` задаёт долю от `min(W,H)` |
| Фавикон и og:image | [`logo.svg`](logo.svg) — тот же контур, залитый `#7B2FF7` |

Знак никогда не рисуется чёрным: контур — электро-фиолетовый, при разлочке тиров поверх ложится
токсично-зелёный штрих. Свечение имитируется широким полупрозрачным штрихом (дешевле `shadowBlur`).
При скролле героя знак наезжает вместе с «камерой» и растворяется — проезд сквозь него.

Пересобрать после замены исходника: `node site/scripts/inject-logo.js` — скрипт вытаскивает `d`
из референса, переписывает `logo.svg` и обновляет `<symbol>` внутри `index.html`.

## 4. Генеративная сцена

`makeScene()` строит один «клин» рекурсивным ветвлением (ломаные сегменты = трайбл-ритм), затем
зеркалит и вращает его `2×S` раз → маска/мандала вокруг логотипа. Каждая группа глубины — один
`Path2D`, поэтому кадр стоит ~70 вызовов `stroke`. Три экземпляра: hero (скролл двигает камеру),
фон блока «Твоя сеть», кабинет (энергия = число рефералов).

Толщина штриха задаётся в экранных px и делится на масштаб трансформы — иначе линия раздувается
вместе со сценой.

## 5. Контент события

Правится в массивах в начале `<script>`:

| Массив | Что описывает |
|---|---|
| `EVENTS` | Афиша. Сейчас одно событие — VIDEO LOUNGE, 12.09.2026, 22:00. Новые добавляются сюда же |
| `EVENT_DATE` | Дата, от которой считается таймер в герое |
| `FORMAT` | Четыре плитки формата (артисты / open-air / тату / маркет) |
| `ACTS` | Лайн-ап, 7 имён |
| `TATTOO`, `MARKET` | Ростеры тату-мастеров и маркета |
| `TICKETS` | Тарифы. **`price: null` = «уточняется»** — проставь числа, и карточки с чекаутом подхватят их |
| `TIERS` | Лестница реферальных наград |

Скидки за тир (−20% с 1 узла, бесплатно с 3) считает `effPrice()`; при `price: null` скидка
показывается как «−20% к финальной цене», а бесплатная проходка работает и без объявленной цены.

## 6. Хранилище (демо-уровень)

| Ключ | Содержимое |
|---|---|
| `rizzoma_mock_db` | `{users:{CODE:{code,name,email,paid,referredBy,referrals[]}}, buyers:{email:CODE}}` |
| `rizzoma_me` | код текущего узла |
| `rizzoma_attribution` | `{code, ts}`, TTL 30 дней |

Реферал засчитывается один раз на уникального покупателя (ключ — e-mail в `buyers`), только после
успешной оплаты, и никогда самому себе. **Это не защищённая от фрода схема**: данные локальны,
редактируются из консоли и не переживают очистку браузера. В продакшне — сервер, платёжный
провайдер и серверная проверка атрибуции.

## 7. Ассеты, которых не хватает

- **Портреты артистов.** Вместо них — детерминированные генеративные сигилы (`sigil()`, seed = хеш
  имени) с честной пометкой `[portrait 3:4]`. Это placeholder, а не подделка: при появлении реальных
  фото блок `.act__sigil` меняется на `<img>` без правки раскладки.
- **Ссылки на соцсети.** В футере стоит `[соцсети — добавить ссылки]`. Реальная ссылка сейчас одна —
  канал UDEL (тату).
- **Цены тарифов** — см. §5.
- QR на билете — заглушка, подписана `QR-ЗАГЛУШКА`.

## 8. QA

- `?devpanel=1` — панель тестирования (+1/+5 рефералов, тест-ссылка, сброс атрибуции, вход в узел по коду, полный сброс).
- `?reduce=1` — принудительно включает статичный режим (эквивалент `prefers-reduced-motion: reduce`).
- `?ref=КОД` — вход по реферальной ссылке (поддерживается и `/r/КОД`).
- Тестовые карты: `4242 4242 4242 4242` → успех, `4000 0000 0000 0002` → отказ.
- Локальный запуск: `python -m http.server 4321 --directory site` (на `file://` localStorage может быть недоступен).
